# AI Workshop – Sokigo Kickoff

**Time:** 1 h 45 min · **Format:** pick one (or more) task cards. Work alone, in pairs, or come hang out at the AI table to chat, ask questions, or work there.

## The task cards

| # | Task | Who it's for | Tools |
|---|------|--------------|-------|
| 1 | Build an App | Coders + curious non-coders | Claude Code (Desktop or terminal) |
| 2 | PRD to Clickable Prototype | UX designers | Claude Design / Claude Desktop |
| 3 | Build a Writing-Style Skill | Technical writers | Claude Desktop |
| 4 | Build a Team of AI Agents | Experienced coders | Claude Code |

Each folder contains a task card (PDF) plus all supporting material. No prerequisites beyond what's on the card.

## Ground rules

- **Done beats perfect.** Every card has a clear "Done when" criterion. Aim for that, not more.
- **Stuck?** Come to the AI table. Installation issues, weird errors, "what do I even type?" – all valid questions.
- **Last 10 minutes:** optional lightning demos, max 1 minute each, straight from your own screen.

## For facilitators (the AI table)

- Most common bottleneck in the first 15 minutes: Claude Code installation/login. Dedicate one person to it.
- Verify venue network in advance. Mobile hotspot as backup.
- Tasks 1 and 4 require Claude Code. Tasks 2 and 3 work with Claude Desktop/claude.ai alone.
- Distribute the folders via a shared repo or download link before the session – participants should not have to retype templates.
- Encourage people to switch cards if they finish early – the cards are independent.

## Shared timeline

| Time | Activity |
|---|---|
| 0:00–0:10 | Intro: cards presented, people choose |
| 0:10–1:30 | Work (facilitators circulate + staff the AI table) |
| 1:30–1:45 | Lightning demos + reflection |
